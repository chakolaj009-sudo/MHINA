חשבון ושברים

עמ' 3–6 בחוברת · יום 1

הסבר

סדר הפעולות: קודם סוגריים, אחר כך חזקות, אחר כך כפל וחילוק (משמאל לימין), ובסוף חיבור וחיסור.

שברים: כדי לחבר או לחסר צריך מכנה משותף. כדי לכפול: מונה במונה ומכנה במכנה. כדי לחלק: הופכים את השבר השני וכופלים.

צמצום: מחלקים את המונה ואת המכנה באותו מספר.

מה צריך לזכור
  • a/b + c/d = (ad + bc)/(bd)
  • a/b · c/d = ac/(bd)
  • a/b : c/d = a/b · d/c

טעות נפוצה: לא מחברים מונים ומכנים בנפרד. 1/2 + 1/3 הוא 5/6 ולא 2/5.

דוגמאות פתורות

דוגמה 1. חשב 15 + 10 : 5 וגם (15 + 10) : 5.

בלי סוגריים קודם חילוק: 10 : 5 = 2, ואז 15 + 2 = 17.

עם סוגריים: 25 : 5 = 5.

דוגמה 2. חשב 2/3 + 3/4.

מכנה משותף 12: 8/12 + 9/12 = 17/12.

דוגמה 3. חשב 3/5 : 9/10.

הופכים וכופלים: 3/5 · 10/9 = 30/45 = 2/3.

חזקות ושורשים

עמ' 7–9 בחוברת · יום 1

הסבר

חזקה היא כפל חוזר: 2³ = 2 · 2 · 2 = 8. בכפל חזקות עם אותו בסיס מחברים מעריכים, בחילוק מחסרים, ובחזקה של חזקה כופלים.

חזקה שלילית היא ההופכי: a⁻ⁿ = 1/aⁿ. כל מספר (שונה מאפס) בחזקת 0 שווה 1.

שורש ריבועי הוא חזקה של חצי: √a = a^(1/2). אפשר לפרק שורש: √(ab) = √a · √b.

מה צריך לזכור
  • aᵐ · aⁿ = aᵐ⁺ⁿ aᵐ : aⁿ = aᵐ⁻ⁿ (aᵐ)ⁿ = aᵐⁿ
  • (ab)ⁿ = aⁿbⁿ a⁰ = 1 a⁻ⁿ = 1/aⁿ
  • √(ab) = √a · √b √(a²) = |a|

טעות נפוצה: (a + b)² אינו a² + b². חוקי החזקות עובדים על כפל וחילוק, לא על חיבור.

דוגמאות פתורות

דוגמה 1. חשב 2³ · 2⁴ ואת (3²)³ : 3⁴.

2³ · 2⁴ = 2⁷ = 128.

(3²)³ = 3⁶, ואז 3⁶ : 3⁴ = 3² = 9.

דוגמה 2. פשט √50.

√50 = √(25 · 2) = 5√2.

דוגמה 3. חשב (1/2)⁻³.

חזקה שלילית הופכת את השבר: (1/2)⁻³ = 2³ = 8.

פתיחת סוגריים ונוסחאות כפל מקוצר

עמ' 10–12 בחוברת · יום 2

הסבר

פתיחת סוגריים: כל איבר בסוגריים הראשונים נכפל בכל איבר בסוגריים השניים.

יש שלוש נוסחאות שכדאי לדעת בעל פה, כי הן חוסכות הרבה חישוב ומופיעות בכל מקום, גם בפיזיקה.

מה צריך לזכור
  • (a + b)² = a² + 2ab + b²
  • (a − b)² = a² − 2ab + b²
  • (a − b)(a + b) = a² − b²

טעות נפוצה: הביטוי (a + b)² אינו a² + b². חסר האיבר האמצעי 2ab.

דוגמאות פתורות

דוגמה 1. פתח: (x + 3)² ואת (2x − 5)².

(x + 3)² = x² + 2 · x · 3 + 9 = x² + 6x + 9.

(2x − 5)² = 4x² − 2 · 2x · 5 + 25 = 4x² − 20x + 25.

דוגמה 2. פתח: (3x − 4)(3x + 4).

זו נוסחת ההפרש: (3x)² − 4² = 9x² − 16.

דוגמה 3. פשט: 3(x − 2)² + (x + 1)(x − 1).

3(x² − 4x + 4) + (x² − 1)

3x² − 12x + 12 + x² − 1 = 4x² − 12x + 11.

פירוק לגורמים

עמ' 13–16 בחוברת · יום 2

הסבר

פירוק לגורמים הוא ההפך מפתיחת סוגריים: הופכים סכום למכפלה. תמיד בודקים קודם גורם משותף, ואחר כך נוסחאות כפל מקוצר, ואחר כך טרינום.

טרינום x² + bx + c: מחפשים שני מספרים שהמכפלה שלהם c והסכום שלהם b. אם הם p ו-q, הפירוק הוא (x + p)(x + q).

לפי קבוצות: מפרקים בנפרד כל זוג איברים ומוציאים גורם משותף חדש.

מה צריך לזכור
  • ab + ac = a(b + c)
  • a² − b² = (a − b)(a + b)
  • a² ± 2ab + b² = (a ± b)²
  • x² + bx + c = (x + p)(x + q), כש-p + q = b ו-pq = c

טעות נפוצה: אחרי הפירוק כדאי לפתוח חזרה ולוודא שיוצא הביטוי המקורי.

דוגמאות פתורות

דוגמה 1. פרק: 6x² + 9x.

הגורם המשותף הגדול הוא 3x: 6x² + 9x = 3x(2x + 3).

דוגמה 2. פרק: x² + 5x + 6.

מחפשים מכפלה 6 וסכום 5: המספרים 2 ו-3.

x² + 5x + 6 = (x + 2)(x + 3).

דוגמה 3. פרק: ax + ay + bx + by.

a(x + y) + b(x + y)

= (a + b)(x + y).

שברים אלגבריים

עמ' 17–19 בחוברת · יום 3

הסבר

שבר אלגברי הוא שבר שיש בו נעלם. הכללים זהים לשברים רגילים, אבל קודם מפרקים לגורמים: כך רואים מה אפשר לצמצם ומהו המכנה המשותף.

אפשר לצמצם רק גורמים (מכפלה), לא איברים בסכום. ב(x + 3)/x לא מצמצמים את ה-x.

מציינים תמיד את הערכים שאסורים (שהמכנה מתאפס בהם).

מה צריך לזכור
  • צמצום: ac/(bc) = a/b (c ≠ 0)
  • חיבור: מפרקים את המכנים, מוצאים מכנה משותף, ואז מחברים מונים
  • חילוק: הופכים את השבר השני וכופלים

טעות נפוצה: אסור לצמצם איבר בסכום. ב-(x + 3)/x לא קורה כלום.

דוגמאות פתורות

דוגמה 1. צמצם: (x² − 9)/(x² − 3x).

מפרקים: מונה (x − 3)(x + 3), מכנה x(x − 3).

מצמצמים x − 3: (x + 3)/x, כשה-x ≠ 0, 3.

דוגמה 2. חשב: 1/(x − 1) + 1/(x + 1).

המכנה המשותף (x − 1)(x + 1).

((x + 1) + (x − 1))/((x − 1)(x + 1)) = 2x/(x² − 1).

דוגמה 3. חשב: (x² − 4)/x : (x + 2)/x².

הופכים וכופלים: (x − 2)(x + 2)/x · x²/(x + 2).

מצמצמים (x + 2) ו-x: x(x − 2).

תרגילים

  1. תשובה

    x + 2, כש-x ≠ 2

  2. תשובה

    2(x + 3)/((x − 3)(x + 3)) = 2/(x − 3)

  3. תשובה

    (x − 2)(x − 3)/((x − 2)(x + 2)) = (x − 3)/(x + 2)

  4. תשובה

    (3(x + 1) + 2x)/(x(x + 1)) = (5x + 3)/(x(x + 1))

  5. תשובה

    ((x + 2) − (x − 2))/((x − 2)(x + 2)) = 4/(x² − 4)

  6. תשובה

    x/(x − 3) − 9/(x(x − 3)) = (x² − 9)/(x(x − 3)) = (x + 3)/x

  7. תשובה

    (a − 1)(a + 1)/a · a²/(a + 1) = a(a − 1)

  8. תשובה

    (x − 3)(x + 3)/(x + 1) · (x − 1)(x + 1)/(x − 3) = (x + 3)(x − 1)

משוואות עם נעלם אחד

עמ' 21–22 בחוברת · יום 3

הסבר

פותרים משוואה כך: פותחים סוגריים, מעבירים את כל האיברים עם x לצד אחד ואת המספרים לצד השני, ומחלקים במקדם של x.

כשיש שברים, כופלים את שני האגפים במכנה המשותף ואז הם נעלמים.

בסוף מציבים את התשובה במשוואה המקורית כדי לוודא.

מה צריך לזכור
  • מעבירים אגף: הופכים סימן
  • כופלים את כל האיברים בשני האגפים באותו מספר

טעות נפוצה: כשמכפילים במכנה משותף, צריך לכפול גם את האיברים בלי שבר, למשל את ה-1 בצד ימין.

דוגמאות פתורות

דוגמה 1. פתור: 3x − 7 = 11.

3x = 18, ולכן x = 6.

דוגמה 2. פתור: (x + 3)/4 − (x − 1)/6 = 1.

מכנה משותף 12: 3(x + 3) − 2(x − 1) = 12

3x + 9 − 2x + 2 = 12, ולכן x + 11 = 12 ו-x = 1.

  2. תשובה

  3. תשובה

  4. תשובה

    5x/6 = 10, ולכן x = 12

  5. תשובה

משוואות ריבועיות

עמ' 23–25 בחוברת · יום 4 (הנושא הכי חשוב)

הסבר

משוואה ריבועית היא משוואה מהצורה ax² + bx + c = 0. קודם מעבירים הכול לצד אחד כדי שיישאר 0 בצד השני.

שיטה 1, פירוק: אם אפשר לפרק לגורמים, כל גורם שווה 0.

שיטה 2, נוסחת השורשים: עובדת תמיד. הביטוי D = b² − 4ac נקרא דיסקרימיננטה: אם D > 0 יש שני פתרונות, אם D = 0 יש פתרון אחד, ואם D < 0 אין פתרון.

בפיזיקה, אחרי שפותרים, בודקים איזה פתרון הגיוני. זמן, למשל, לא יכול להיות שלילי.

מה צריך לזכור
  • x = (−b ± √(b² − 4ac))/(2a)
  • D = b² − 4ac
  • x² + bx = 0 → x(x + b) = 0 x² = k → x = ±√k

טעות נפוצה: שוכחים להעביר הכול לצד אחד לפני שקובעים את a, b ו-c. וכשמחלקים ב-x מאבדים פתרון: עדיף להוציא גורם משותף.

דוגמאות פתורות

דוגמה 1. פתור: x² − 5x + 6 = 0.

פירוק: (x − 2)(x − 3) = 0, ולכן x = 2 או x = 3.

דוגמה 2. פתור: 2x² + 3x − 2 = 0.

a = 2, b = 3, c = −2, ולכן D = 9 + 16 = 25.

x = (−3 ± 5)/4, כלומר x = 1/2 או x = −2.

דוגמה 3. פתור: x² + 4x + 5 = 0.

D = 16 − 20 = −4 < 0, ולכן אין פתרון.

דוגמה 4. לאילו ערכי m למשוואה x² − 6x + m = 0 יש פתרון אחד בלבד?

פתרון אחד כש-D = 0: 36 − 4m = 0, ולכן m = 9.

תרגילים

  1. תשובה

    (x − 3)(x − 4) = 0, ולכן x = 3 או x = 4

  2. תשובה

    x = ±3

  3. תשובה

    x(x + 5) = 0, ולכן x = 0 או x = −5

  4. תשובה

    (x − 5)(x + 3) = 0, ולכן x = 5 או x = −3

  5. תשובה

    D = 25 + 24 = 49, ולכן x = (5 ± 7)/4: x = 3 או x = −1/2

  6. תשובה

    D = 4 − 20 < 0, ולכן אין פתרון

  7. תשובה

    מחלקים ב-3: x² − 4x + 4 = 0, כלומר (x − 2)² = 0, ולכן x = 2 (פתרון אחד)

  8. תשובה

    x − 3 = ±4, ולכן x = 7 או x = −1

  9. תשובה

    x² + 2x − 3 = 0, כלומר (x + 3)(x − 1) = 0: x = −3 או x = 1

  10. תשובה

  11. תשובה

חילוק פולינומים ומשוואות ממעלה שלישית (לא חובה)

עמ' 20 ו-26–27 בחוברת · יום 4, אם יש כוח

הסבר

אם x = a הוא פתרון של פולינום, אז הפולינום מתחלק ב-(x − a) בלי שארית. כך מורידים משוואה ממעלה שלישית למשוואה ריבועית.

מנחשים פתרון (מנסים את המספרים 1, −1, 2, −2, …), מחלקים, ופותרים את הריבועית שנשארת.

חילוק פולינומים עובד כמו חילוק ארוך: מחלקים את האיבר הראשון, כופלים, מחסרים, וחוזרים.

מה צריך לזכור
  • אם P(a) = 0 אז P(x) = (x − a) · Q(x)

טעות נפוצה: אחרי החילוק בודקים שהשארית אפס. אם לא, הניחוש של הפתרון לא נכון.

דוגמאות פתורות

דוגמה 1. חלק: (x² + 5x + 6) : (x + 2).

x² : x = x, כופלים x(x + 2) = x² + 2x ומחסרים: נשאר 3x + 6.

3x : x = 3, כופלים 3(x + 2) = 3x + 6, ונשאר 0. התוצאה x + 3.

דוגמה 2. פתור: x³ − 6x² + 11x − 6 = 0.

מנסים x = 1: 1 − 6 + 11 − 6 = 0, לכן זה פתרון.

מחלקים ב-(x − 1) ומקבלים x² − 5x + 6.

x² − 5x + 6 = (x − 2)(x − 3). הפתרונות: x = 1, 2, 3.

תרגילים

    x(x − 1)(x + 1) = 0, ולכן x = 0, 1, −1

  2. תשובה

    x(x − 1)(x − 3) = 0, ולכן x = 0, 1, 3

  3. תשובה

    חילוק ב-(x − 1) נותן x² − x − 6 = (x − 3)(x + 2). הפתרונות x = 1, 3, −2

  4. תשובה

    x² − 2x + 4. בדיקה: (x + 2)(x² − 2x + 4) = x³ + 8

הסבר

מה צריך לזכור

טעות נפוצה: אחרי שפתרת, חובה לבדוק שהפתרון לא מאפס מכנה. פתרון כזה אינו פתרון של המשוואה.

דוגמאות פתורות

דוגמה 1. פתור: 2/x + 3/(x + 1) = 2.

אסור: x ≠ 0, −1. כופלים ב-x(x + 1): 2(x + 1) + 3x = 2x(x + 1).

5x + 2 = 2x² + 2x, ולכן 2x² − 3x − 2 = 0.

x = (3 ± 5)/4: x = 2 או x = −1/2. שניהם מותרים.

דוגמה 2. פתור: x²/(x − 3) = 9/(x − 3).

אסור: x ≠ 3. כופלים ב-(x − 3): x² = 9, ולכן x = 3 או x = −3.

הפתרון x = 3 אסור. התשובה: x = −3.

  1. תשובה

    x = 2

  2. תשובה

    1/x = 1/4, ולכן x = 4

  3. תשובה

    5 = 2(x − 1), ולכן x = 3.5

  4. תשובה

    x = 3x − 6, ולכן x = 3

  5. תשובה

    2(x + 1) = 3(x − 1), ולכן 2x + 2 = 3x − 3 ו-x = 5

  6. תשובה

    x² = 16, אבל x ≠ 4, ולכן x = −4

המעגל הטריגונומטרי ונוסחאות הזוויות

עמ' 78 בחוברת הטריגונומטריה · יום 3

הסבר

בזווית חדה במשולש ישר-זווית: sin α הוא היחס בין הניצב שמול הזווית ליתר, cos α הוא היחס בין הניצב שליד הזווית ליתר, ו-tan α הוא היחס בין הניצב שמול לניצב שליד.

על המעגל: מציירים מעגל ברדיוס 1. לזווית α מתאימה נקודה על המעגל, וקואורדינטות הנקודה הן (cos α, sin α). לכן cos הוא הרוחק האופקי (ציר x) ו-sin הוא הגובה (ציר y).

סימנים לפי רבע: ברבע 1 (0° עד 90°) הכול חיובי. ברבע 2 רק sin חיובי. ברבע 3 רק tan ו-cot חיוביים. ברבע 4 רק cos חיובי.

כלל הנוסחאות (90°, 180°, 270°, 360°): עם 90° ו-270° הפונקציה מתחלפת (sin ↔ cos, tan ↔ cot). עם 180° ו-360° היא נשארת. את הסימן קובעים לפי הרבע של הזווית, כאילו α חדה.

ערכים שכדאי לדעת: sin 30° = 1/2, sin 45° = √2/2, sin 60° = √3/2, cos 30° = √3/2, cos 45° = √2/2, cos 60° = 1/2, tan 45° = 1.

מה צריך לזכור
  • sin(180° − α) = sin α cos(180° − α) = −cos α
  • sin(90° + α) = cos α cos(90° + α) = −sin α
  • sin(−α) = −sin α cos(−α) = cos α tan(−α) = −tan α
  • sin(360° − α) = −sin α cos(360° − α) = cos α

טעות נפוצה: שוכחים לבדוק את הרבע. למשל cos 120° הוא שלילי, כי ברבע 2 רק sin חיובי.

240° = 180° + 60°, ברבע 3, שם cos שלילי.

עם 270° הפונקציה מתחלפת: tan → cot.

הזווית 270° − α ברבע 3, שם tan חיובי. לכן tan(270° − α) = cot α.

הסבר

הזהות החשובה ביותר: sin²α + cos²α = 1. ממנה יוצאות כל האחרות.

להוכיח זהות: מתחילים מהצד המסובך יותר, ומגיעים לצד השני בעזרת הנוסחאות. לא מעבירים אגפים.

טיפ: כשיש tan או cot, מחליפים אותם ב-sin וב-cos. כשיש 1 − cos²α, מחליפים ב-sin²α, ולהפך.

חישוב ערכים: אם נתון ערך אחד של זווית ורבע, מוצאים את השאר בעזרת sin²α + cos²α = 1 ובודקים סימן לפי הרבע.

מה צריך לזכור
  • sin²α + cos²α = 1
  • tan α = sin α / cos α cot α = cos α / sin α tan α · cot α = 1
  • 1 + tan²α = 1/cos²α 1 + cot²α = 1/sin²α
  • sin(90° − α) = cos α cos(90° − α) = sin α

טעות נפוצה: בהוכחה לא מתחילים מהמסקנה. מתחילים מצד אחד ומגיעים לצד השני.

דוגמאות פתורות

דוגמה 1. הוכח: cot α · sin α = cos α.

צד שמאל: (cos α / sin α) · sin α.

מצמצמים sin α ומקבלים cos α, כמו צד ימין.

דוגמה 2. הוכח: (1 − cos α)(1 + cos α)/cos²α = tan²α.

מונה: 1 − cos²α = sin²α.

לכן צד שמאל sin²α/cos²α = tan²α.

דוגמה 3. נתון sin α = 3/5, כש-0° < α < 90°. מצא cos α ו-tan α.

cos²α = 1 − 9/25 = 16/25, ולכן cos α = 4/5 (חיובי ברבע 1).

tan α = (3/5)/(4/5) = 3/4.

  4. תשובה

תנועה בקטעים: העתק, דרך ומהירות ממוצעת

באתר: ש.מ למקוטעין, נושאים 1–3 · יום 2

הסבר

כשהתנועה מורכבת מכמה קטעים במהירויות שונות, מחשבים כל קטע בנפרד ואז מחברים.

העתק = מקום סופי פחות מקום התחלתי (עם כיוון). דרך = כל המרחק שעבר הגוף (תמיד חיובית).

מהירות ממוצעת = העתק כולל ÷ זמן כולל (וקטור). מהירות ממוצעת בגודל (מהירות סקלרית) = דרך ÷ זמן.

מהירות ממוצעת היא לא ממוצע של המהירויות, אלא אם הזמנים שווים.

מה צריך לזכור
  • מהירות ממוצעת = העתק כולל ÷ זמן כולל
  • מהירות סקלרית ממוצעת = דרך כוללת ÷ זמן כולל
  • אם חוזרים לנקודת ההתחלה, ההעתק הוא 0

טעות נפוצה: ממוצע של שתי מהירויות נכון רק אם הזמנים בכל קטע שווים. אם המרחקים שווים, יוצא ממוצע אחר.

תאוצה קבועה: מושגים ושתי משוואות

באתר: שוות תאוצה א, נושאים 1–6 · יום 2–3

הסבר

תאוצה היא כמה המהירות משתנה בכל שנייה: a = Δv/Δt. היחידה היא מטר לשנייה בריבוע.

כיוון התאוצה: אם התאוצה והמהירות באותו כיוון, הגוף מאיץ (מהירות גדלה). אם בכיוונים הפוכים, הגוף מאט. גוף יכול להאט, לעצור ולהתחיל לנוע לכיוון ההפוך.

כשהתאוצה קבועה: v = v₀ + a·t ו-x = x₀ + v₀·t + ½·a·t².

בגרף מהירות–זמן: השיפוע הוא התאוצה והשטח הוא ההעתק.

בלימה: כשגוף עוצר, מהירותו הסופית 0. תאוצת בלימה שלילית (אם כיוון התנועה חיובי).

מה צריך לזכור
  • a = Δv/Δt
  • v = v₀ + a·t
  • x = x₀ + v₀·t + ½·a·t²
  • העתק = (v₀ + v)/2 · t (רק כשהתאוצה קבועה)

טעות נפוצה: בבלימה מציבים a שלילית (או v₀ שלילית, אם הכיוון החיובי הפוך). שוכחים סימן ומקבלים זמן שלילי.

גרפים בתנועה בתאוצה קבועה

באתר: שוות תאוצה ב, נושאים 8–12 · יום 3

הסבר

גרף תאוצה–זמן: כל קטע הוא קו אופקי. השטח מתחתיו הוא שינוי המהירות.

גרף מהירות–זמן: כל קטע הוא קו ישר. השיפוע הוא התאוצה, והשטח מתחתיו הוא ההעתק. שטח מתחת לציר הזמן נחשב שלילי.

שלוש המשוואות ושלושת הגרפים

באתר: שוות תאוצה ג, נושאים 13–18 · יום 4–5

הסבר

שלוש המשוואות של תנועה בתאוצה קבועה: v = v₀ + a·t, x = x₀ + v₀·t + ½·a·t² ו-v² = v₀² + 2·a·(x − x₀).

איך בוחרים משוואה: לכל משוואה חסר גודל אחד. במשוואה הראשונה חסר x, בשנייה חסר v, ובשלישית חסר t. בוחרים את המשוואה שבה חסר הגודל שלא נתון ולא מבקשים.

המשוואה השלישית חשובה בבלימה: כשלא נתון זמן, היא נותנת קשר בין מהירות, תאוצה ומרחק.

שלושה גרפים: x(t) הוא פרבולה, v(t) קו ישר, ו-a(t) קו אופקי. שיפוע של x(t) הוא v. שיפוע של v(t) הוא a. שטח מתחת ל-v(t) הוא Δx. שטח מתחת ל-a(t) הוא Δv.

מרחק בלימה כולל: בזמן תגובה הגוף נע במהירות קבועה, ואחר כך בולם. מחברים את שני המרחקים.

מה צריך לזכור
  • v = v₀ + a·t (בלי x)
  • x = x₀ + v₀·t + ½·a·t² (בלי v)
  • v² = v₀² + 2·a·(x − x₀) (בלי t)
  • מרחק בלימה: x = v₀²/(2|a|)

טעות נפוצה: בבלימה מרחק העצירה גדל פי 4 כשהמהירות מוכפלת, כי הוא תלוי ב-v₀².

כוחות וחוקי ניוטון

פרק 3 בקורס (מושגי יסוד, חוק ראשון, חוק שני) · יום 4–5

הסבר

כוח נמדד בניוטון (N). כוח הוא וקטור. הכוח השקול הוא הסכום הווקטורי של כל הכוחות על הגוף.

כוחות נפוצים: משקל W = m·g (כלפי מטה, ובחוברת g = 10), כוח נורמלי N (מהמשטח, ניצב אליו), כוח מתיחות T (בחוט), חיכוך (מנוגד לתנועה).

חוק ראשון: אם סכום הכוחות על גוף הוא אפס, הגוף נמצא במנוחה או נע במהירות קבועה.

חוק שני: ΣF = m·a. סכום הכוחות (בכיוון החיובי שבחרת) שווה למסה כפול התאוצה.

שלבים לפתרון: (1) מציירים את הכוחות על הגוף, (2) בוחרים כיוון חיובי, (3) כותבים ΣF = m·a, (4) פותרים. אם צריך מהירות או מרחק, מחברים את התאוצה למשוואות התנועה.

מעלית: כשלמעלה חיובי, T − m·g = m·a, כלומר T = m(g + a). אם המעלית מאיצה למטה, a שלילית ו-T קטן.

מה צריך לזכור
  • ΣF = m·a
  • W = m·g (כש-g = 10 מ'/ש²)
  • T − m·g = m·a (מעלית, למעלה חיובי)
  • מהירות קבועה ⇒ ΣF = 0

טעות נפוצה: מחברים את הכוחות בסימן: כוח לכיוון החיובי בפלוס, לכיוון ההפוך במינוס. וחשוב לא לשכוח את המשקל.
